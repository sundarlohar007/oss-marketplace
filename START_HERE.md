# See the project structure

If you want to understand what we built, here are the key files:

```
oss-marketplace/
├── README.md          ← Start here! Explains everything
├── CONTRIBUTING.md    ← How to help build this
├── ROADMAP.md        ← What we're building next
├── LICENSE           ← MIT license (free forever)
└── cli/
    └── oss_profile.py  ← The CLI tool that generates profiles
```

Run the CLI tool:
```bash
cd cli
python oss_profile.py create --github octocat
```
