# OSS Marketplace Web Dashboard

Next.js 15 frontend for the OSS Marketplace platform.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase (Auth + Database)
